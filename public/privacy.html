The apps

Phone Usage and Mac Usage keep usage records on your device. Neither app includes advertising, analytics, an account service, or usage uploads.

Phone Usage reads Android's usage event stream and daily usage totals. It records app and screen-state events, sessions, opens, and related usage timestamps. It does not declare Android's INTERNET permission. It does not access messages, contacts, call logs, location, camera, microphone, or clipboard.

Mac Usage records app names, bundle identifiers, session IDs, and start/end timestamps. It reads the foreground application and system input idle counters. It does not capture individual key presses, app contents, window titles, websites, screenshots, or clipboard data. It does not request Accessibility or Screen Recording access.

Storage and deletion

History is retained locally until you manually delete it. JSON exports go to the location you choose; if you share an export, its records become available to that recipient. Android uninstalling removes the app's private storage. On Mac, removing the app leaves its Application Support history in place.

This website and downloads

This website has no advertising, analytics scripts, accounts, or application-usage uploads. Cloudflare hosts it and may process ordinary request information, such as IP address and browser headers, to serve and secure the site. The website server reads public GitHub release metadata to find valid downloads.

Downloads and source links are hosted by GitHub. Following those links sends an ordinary request to GitHub under its own privacy policy. Your local app usage history is never included in that request.

Open source

The source code is publicly available under the MIT license. Review Phone Usage, Mac Usage, and this website. Questions or issues can be raised in the relevant repository; avoid posting personal usage exports in public issues.
